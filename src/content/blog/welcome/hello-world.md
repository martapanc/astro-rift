This is the first post on this awesome blog! Welcome to **AstroRift** — a modern blog built with Astro 5 and React, designed to be fast, flexible, and a joy to write in.

## A new beginning

Every blog starts somewhere. This one starts here, with a blank page and a lot of potential. Whether you're planning to write about technology, travel, cooking, or the slow passage of time, the important thing is that you've started.

## What's coming

Over the next few posts, we'll explore what AstroRift can do. Here's a rough roadmap:

1. A **typography showcase** — every heading level, list style, quote, code block, and table
2. A **getting started guide** — cloning, configuring, and deploying
3. An **MDX demo** — mixing React components directly into a post

For now, here are a few things worth knowing about the template:

- Posts live in `src/content/blog/` as Markdown or MDX files
- Set `featured: true` in the frontmatter to include a post in the home page slideshow
- Dark mode is toggled from the header and persists across page loads
- Full-text search is available in the sidebar, powered by Pagefind
